# 黄浦江灯光 · Huangpu Lights

上海陆家嘴 3D 讲解页——单文件 Three.js 场景，无构建步骤，直接用浏览器打开。

## 内容

- 东方明珠、上海中心、环球金融中心、金茂大厦四塔几何重建
- 外滩万国建筑群、黄浦江游船与水面粒子
- 7 站导览 + 时间滑块（昼夜）+ 四季切换
- 卡通渲染（MeshToonMaterial）+ 暖/冷双补光 + ACES 色调映射

## 技术

- Three.js r160（jsDelivr CDN import map，本地零依赖）
- InstancedMesh 窗户系统（暖/冷随机窗色，昼夜联动）
